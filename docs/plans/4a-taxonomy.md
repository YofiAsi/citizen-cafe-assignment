# Plan 4a — Taxonomy Spec

The authoritative enumeration of tiers, levels, and types. Provided by the project owner; seed data and dropdowns must match this exactly.

## Taxonomy

| Tier | Order | Levels (in order) | Types |
|---|---|---|---|
| Foundation (core vocabulary) | 1 | Red, Orange, Pink, Yellow | — |
| Flow (conversational fluency) | 2 | Light Blue, Blue, Lime, Green | — |
| Freedom (native-level mastery) | 3 | Dark Green, Turquoise, Indigo, Purple | Dark Green: 1–4 · Turquoise: 1–4 · Indigo: 1–6 · Purple: — |

## Decks

A deck is a level with no types, or a level + type pair. Every deck gets ~10 Hebrew ↔ English pairs.

- **Foundation**: 4 decks (Red, Orange, Pink, Yellow)
- **Flow**: 4 decks (Light Blue, Blue, Lime, Green)
- **Freedom**: 15 decks (Dark Green 1–4, Turquoise 1–4, Indigo 1–6, Purple)
- **Total**: 23 decks ≈ 230 pairs

## Notes

- Types are numeric labels (1, 2, 3, …), not names.
- Purple is a Freedom level with no types, so the Type dropdown must not appear for it.
- Level display names are their colour names; the actual colour values come from the Design Bible tokens (plan 8a).
- Stable identifiers (slugs/IDs) for these entries are defined by the data model plans (3a/3b), not here.
